## Accuracy and artwork provenance

- UI images come from actual Flutter widgets in this repository, captured at 1170 × 2532 with the application's real fonts. No AI-generated UI, invented buttons, or substituted dashboard design.
- Sessions, streaks, routines, and schedules are fictional demonstration data. They are not performance promises or user testimonials.
- Advertising is disabled in the isolated capture harness; no live ad requests or real user data were used. Production ad behavior is unchanged.
- No promotion of the disabled rewarded 45-minute feature, paid remove-ads product, cloud synchronization, shared household accounts, or obsolete Arunika health/journal features.
- “Core cleaning tools work offline” deliberately refers to the local app features, not to advertising.
- The store icon extends the repository's existing three-sparkle geometry and jade colors. Its canvas is full-bleed, without baked-in rounded corners or an external shadow. Installing it as a launcher icon is outside this asset-only task.
- The room illustration was generated with the built-in image-generation tool. Prompt: see `prompts.md`.
- The video score is a new procedural instrumental generated by `make-score.mjs`, with no third-party music samples. No voiceover is included; the story is readable with sound off.
- Font: Plus Jakarta Sans files already present in the app, reused for brand consistency.

## Source and reproduction

The editable project lives in `creative-studio/` at repository root. A portable snapshot is supplied in `source-remotion/` in the delivery package.

Inside the Remotion project:

```sh
npm ci
node scripts/make-score.mjs
npx remotion studio --no-open
node scripts/render-assets.mjs stills
node scripts/render-assets.mjs video
```

The renderer writes to `../store/creative-2026-09`. To use the portable source elsewhere, change the output root in `scripts/render-assets.mjs`.

To refresh actual app captures from repository root:

```sh
flutter test test/store_capture_test.dart --dart-define=STORE_CAPTURES=true
```

Copy the generated source-captures PNGs to `creative-studio/public/`, then render again.
